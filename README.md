## Featured project

### [ReSpect-TTA](https://github.com/yqy123456/CPS3830-ReSpect-TTA)

**Residual-conditioned spectral adaptation for time-series forecasting**

How can a frozen forecasting model use its recent errors to adapt? ReSpect-TTA
uses residual information to generate a complex-valued correction in the
frequency domain, with a learned gate controlling the final adjustment.

**My contribution:** design of this spectral adapter variant and its method

foundation remain collaborative and upstream work.

## Selected work

### [Spam Email Classifier](https://github.com/yqy123456/CPS3320-Spam-Email-Classifier)

An applied machine learning project combining a Keras neural network, three
classical baselines, saved evaluation artifacts, and a Tkinter interface.
The recorded fixed-split evaluation reports **98.29% accuracy** and **98.38% F1**
for the neural network. The original training dataset is not bundled.

*Python · Keras / TensorFlow · scikit-learn · CPS3320*

### [WKU Admission System](https://github.com/yqy123456/CPS3962-WKU-Admission-System)

A collaborative PHP/MySQL application covering student applications, document
verification, staff review, and admission tracking. My documented contribution
includes student applications, document uploads, email testing, and evidence
collection. This repository is a fork of the team project.

*PHP · MySQL · Role-based workflows · CPS3962 group project*

### [SVM on Iris](https://github.com/yqy123456/CPS4982-SVM-Iris)

A controlled study of the RBF-SVM penalty parameter, with decision-boundary
visualizations, a literature review, and an experiment report. Four C values
are compared under the same data split and preprocessing.

*Python · scikit-learn · Experimental analysis · CPS4982*
